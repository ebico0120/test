# ベトナム語5級トレーナー

ベトナム語検定5級レベルの単語・表現を繰り返し練習するWebアプリ（単語457語・表現73文・会話34組）（Android Chrome向け、ハノイの発音基準）。

## 主な機能

- **🏠 家モード / 🚃 電車モード** をヘッダーでワンタップ切り替え
  - 家：音声が自動再生され、マイクで発話練習（音声認識で判定）
  - 電車：音は出さず、発話は「心の中で言ってから答えを確認」に。設定で「イヤホン使用」をONにすると、ヒアリングも使える
- 練習メニュー：単語4択（両方向）／ヒアリング／声調の聞き分け／つづり（文字タイルを選ぶ）／文の並べ替え／会話の受け答え／発話
- 間隔反復で復習（正解ごとに 1→3→7→14→30→60日、間違えると最初から）
- 記録画面（7日間の回答数、カテゴリ別の習得、苦手な単語）と単語一覧
- オフライン対応（PWA）。ホーム画面に追加できる

## 使い方

1. GitHub の Settings → Pages で、このブランチの `/`（root）を公開する
2. Android の Chrome で公開URLを開き、メニューの「ホーム画面に追加」
3. 音声が出ない場合：Android の設定 →「テキスト読み上げの出力」→ Google音声サービスでベトナム語の音声データをインストール

ローカルで試す場合は `python3 -m http.server` で起動して `http://localhost:8000` を開く。

## 単語の追加

`js/data.js` の各配列の **末尾** に `['ベトナム語', '日本語']` を追加する（途中に入れると学習記録の対応がずれる）。
ファイルを更新したら `sw.js` の `VERSION` を上げる。
